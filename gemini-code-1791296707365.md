## CONTEXT & SYSTEM SPECIFICATIONS (INGESTED FROM PRD)

### 1. Core Architecture & Tech Stack
- **Runtime:** Python 3.11+ managed via `uv` (fast dependency resolution) or `poetry`.
- **Orchestration Core:** `LangGraph` (>=0.2.x) state machine utilizing deterministic graphs, cyclic flows, and built-in state checkpointing (SQLite for dev, PostgreSQL-ready for prod).
- **Model Gateway:** Unified multi-provider abstraction (`LiteLLM`) supporting Azure OpenAI, AWS Bedrock, Anthropic, and self-hosted open-weights models via `vLLM` / `Ollama`.
- **Middleware Interceptor Chain:** Pre- and post-node interceptors enforcing:
  1. Input sanitization (Prompt injection defense, PII/PHI redaction).
  2. OpenTelemetry (OTel) distributed tracing exporting to `Langfuse`.
  3. Cost/budget thresholds (terminating runaway token consumption).
  4. Human-In-The-Loop (HITL) interruption on mutating/high-risk tools.
  5. Immutable, cryptographically hashed audit trails (SHA-256 Merkle chain for FDA 21 CFR Part 11 compliance).
- **Tooling & Protocols:** Dynamic Tool Registry with Pydantic v2 schema validation, risk tiering (`READ_ONLY` vs `MUTATING_HIGH_RISK`), and Anthropic Model Context Protocol (`MCP`) client integration.
- **Pre-flight Synthetic Evaluation:** Integrated test runner executing golden test datasets via `Ragas` / `DeepEval` measuring Tool Call Fidelity, Groundedness/Faithfulness, and Relevancy.
- **Delivery Formats:** Standalone Python library (`src/harness/`), FastAPI runtime server (`/run`, `/resume`, `/health`, `/audit`), and Scaffolding CLI (`harness init <agent-name>`).

### 2. Multi-Agent Operational Roles
